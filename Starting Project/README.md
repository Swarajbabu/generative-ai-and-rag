# Starting Project

This folder contains the initial setup, dependency specifications, and hands-on notebooks for Generative AI and RAG.

- **`notebook/document.ipynb`**: Hands-on exploration of LangChain `Document` schemas and metadata.
- **`data/`**: Place raw documents (PDFs, text files) here for RAG ingestion.
- **`pyproject.toml` & `uv.lock`**: Managed with `uv`.

For full documentation and setup instructions, see the root [README.md](../README.md).
